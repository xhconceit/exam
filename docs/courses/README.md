## 难度说明

- **★☆☆☆（低）**：以识记为主，短期内较容易形成应试能力。
- **★★☆☆（中）**：需要理解与记忆结合，按计划学习通常可控。
- **★★★☆（中高）**：知识量、应用题或实践要求较明显，需要持续练习。
- **★★★★（高）**：数学、算法、系统原理或综合实践要求高，零基础不宜短期突击。

> 课程、教材和实践要求最终以广东省自学考试管理系统及华南师范大学当年通知为准。旧计划、旧课程代码资料只作知识补充。
