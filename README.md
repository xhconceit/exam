# 华南师范大学自考规划

> [按课程类别查看学习资料](./docs/courses/README.md)

## 基本情况

- 主考学校：华南师范大学
- 专业：计算机科学与技术（专升本）
- 专业代码：080901
- 目标：取得本科毕业证，并申请华南师范大学学士学位
- 当前已通过：15043《中国近现代史纲要》，65分
- 备考基础：计算机相关课程零基础
- 当前策略：英语安排在后期考试

## 笔试冲刺目标（按2026年10月全部未通过估算）

- 目标：**在2028年4月考期完成全部笔试，并在成绩公布后确认全部合格**；此阶段目标**不包含5项实践考核和毕业论文**。
- 本专业按现行思政课调整后的计划共有15门笔试。项目目前只记录已通过`15043`中国近现代史纲要，因此保守按**剩余14门笔试**规划。2026年10月成绩公布后，按实际通过科目更新剩余数量。
- 报考策略：**每个考期尽量报满该专业可报、时间不冲突且尚未通过的笔试时段**。准备不足的科目也参加考试，熟悉题型；报满不等于复习时间平均分配，也不等于保证全部通过。
- 复习策略：每期指定1～2门“主攻通过”，其他报考科目作为“次重点/体验考试”。已通过的课不再为凑满时段重复报考；如果当期可报的未通过课程不足4门，就报实际可报数量。

### 2027年1月：4门全部报考

这4门的考试时段互不冲突，报考建议按难度和现有基础分配复习精力：

| 复习优先级 | 课程代码 | 课程名称 | 策略 |
| --- | --- | --- | --- |
| 主攻① | 03344 | 信息与网络安全管理 | 偏理解、记忆，优先争取通过 |
| 主攻② | 13009 | 数据库原理与技术 | 系统学习概念并练题，争取通过 |
| 次重点/体验③ | 13011 | 人工智能与大数据 | 概念面广，先熟悉题型，力争超预期通过 |
| 次重点/体验④ | 08074 | 计算机高级程序设计 | 编程基础要求高，先积累考试经验 |

“主攻/体验”只是复习时间分配，不表示后两门可以缺考。报名和考试均以当期官方安排及个人报考资格为准。

### 后续考期与难度安排

2027年1月之后，至2028年4月目标考期，预计还有2027年4月、10月和2028年1月、4月等考期。**这些考期的具体课程、时段尚未全部公布**，不能提前保证每期都能报4门，或把某门课固定到某一天。官方计划公布后逐时段填报：优先安排准备充分、开考机会少的未通过课程，遇到撞时段则取舍；成绩公布后优先安排未通过课程重考。

学习难度按当前“计算机课程零基础、数学约小学水平、英语约小学三年级水平”做个人化排序，并非官方难度分级：

| 层级 | 课程代码与名称 | 安排原则 |
| --- | --- | --- |
| 先争取通过 | `15040`习近平新时代中国特色社会主义思想概论、`15044`马克思主义基本原理、`13005`软件工程、`03344`信息与网络安全管理 | 穿插在前期考期，建立合格成绩 |
| 有基础后推进 | `13009`数据库原理与技术、`13015`计算机系统原理、`13011`人工智能与大数据、`13013`高级语言程序设计、`08074`计算机高级程序设计、`13180`操作系统、`13003`数据结构与算法 | 编程与计算机基础同步补，依公布的开考时段和备考进度安排 |
| 提前长期补基础 | `00023`高等数学（工本）、`02324`离散数学、`13000`英语（专升本） | **现在开始学，不要等到计划报考的当季**；尽量在2027年内参加首次考试，给2028年留重考机会 |

英语先每天学习30～45分钟，从发音、基础词汇和简单句逐步过渡到真题阅读；数学先每天学习45～60分钟，从分数、方程、代数式、函数补起，再进入高等数学和离散数学。时间可根据当天其他科目的主攻任务调整，但尽量保持连续性。

**可行性提醒：**按2026年10月全部未通过计算，2027年1月至2028年4月需要通过14门笔试，目标激进，重考空间有限。2028年4月“考完”不等于当月已公布全部合格成绩；最终是否达成以成绩公布及广东省自学考试管理系统中的个人专业计划、顶替结果为准。

在每天能够稳定学习2.5～3小时的情况下，可增加：

| 优先级 | 课程代码 | 课程名称 | 建议 |

## 15040复习依据

- 官方名称：《习近平新时代中国特色社会主义思想概论课程自学考试大纲》
- 制定单位：全国高等教育自学考试指导委员会
- 大纲版本：2024年8月
- 教材：《习近平新时代中国特色社会主义思想概论》，高等教育出版社、人民出版社
- [官方考试大纲及参考样卷（PDF）](https://www.jseea.cn/webfile/upload/2025/01-15/11-25-2801141922432644.pdf)

复习优先顺序：

1. 每章“本章重点”
2. “识记”知识点（主要对应选择题）
3. “领会”知识点（选择题、简答题）
4. “应用”知识点（材料题）
5. 考试日前12个月以内的国内外时事
6. 官方参考样卷、练习题和错题

2026年10月考试的时政范围，应按具体考试日期向前倒推12个月，大致为2025年10月至2026年10月考试日。教材理论内容不按12个月变化，只有“形势与政策”部分按该范围准备。

## 两个月学习安排

### 第1～4周

- 每天学习15040约1小时
- 每天学习软件工程约1～1.5小时
- 完成教材、大纲知识点和章节练习

### 第5～6周

- 按考试大纲背诵重点
- 集中练习选择题、简答题和材料题
- 整理错题与易混概念

### 第7周

- 完整做模拟卷
- 按考试时间进行限时训练
- 补强薄弱章节

### 第8周

- 背诵高频考点
- 补充截至考试日前的时政内容
- 回顾错题，不再大量增加新资料

## 毕业时间判断

如果2026年10月通过4门，2027年仍需完成多门笔试、实践课和毕业论文。理想情况下，可以争取在2027年完成大部分或全部考核，并赶上2027年12月毕业申请；但实践课、论文批次、考试时间冲突和成绩公布时间都可能影响进度。

较稳妥的目标是：

- 2027年：集中完成剩余笔试和实践考核，尽早报名毕业论文
- 2027年末或2028年：申请并取得毕业证
- 毕业后：按华南师范大学当时有效的学位规定及时申请学士学位

学位申请的现行条件（课程平均分、英语统考认定、论文答辩及申请期限）见[华南师范大学自考本科学士学位要求整理](./docs/references/official/华南师范大学自考本科学士学位要求（据教学〔2025〕9号整理）.md)。

为了申请学位，不应只以60分为复习目标。各科尽量争取70分以上，并特别关注英语、毕业论文成绩和学位申请期限。
