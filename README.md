
不建议零基础考生在两个月内同时选择高等数学、离散数学、数据结构、操作系统等多门技术课程。

## 15040复习依据

- 官方名称：《习近平新时代中国特色社会主义思想概论课程自学考试大纲》
- 制定单位：全国高等教育自学考试指导委员会
- 大纲版本：2024年8月
- 教材：《习近平新时代中国特色社会主义思想概论》，高等教育出版社、人民出版社
- [官方考试大纲及参考样卷（PDF）](https://www.jseea.cn/webfile/upload/2025/01-15/11-25-2801141922432644.pdf)

复习优先顺序：

1. 每章“本章重点”
2. “识记”知识点（主要对应选择题）
3. “领会”知识点（选择题、简答题）
4. “应用”知识点（材料题）
5. 考试日前12个月以内的国内外时事
6. 官方参考样卷、练习题和错题

2026年10月考试的时政范围，应按具体考试日期向前倒推12个月，大致为2025年10月至2026年10月考试日。教材理论内容不按12个月变化，只有“形势与政策”部分按该范围准备。

## 两个月学习安排

### 第1～4周

- 每天学习15040约1小时
- 每天学习软件工程约1～1.5小时
- 完成教材、大纲知识点和章节练习

### 第5～6周

- 按考试大纲背诵重点
- 集中练习选择题、简答题和材料题
- 整理错题与易混概念

### 第7周

- 完整做模拟卷
- 按考试时间进行限时训练
- 补强薄弱章节

### 第8周

- 背诵高频考点
- 补充截至考试日前的时政内容
- 回顾错题，不再大量增加新资料

## 毕业时间判断

如果2026年10月通过4门，2027年仍需完成多门笔试、实践课和毕业论文。理想情况下，可以争取在2027年完成大部分或全部考核，并赶上2027年12月毕业申请；但实践课、论文批次、考试时间冲突和成绩公布时间都可能影响进度。

较稳妥的目标是：

- 2027年：集中完成剩余笔试和实践考核，尽早报名毕业论文
- 2027年末或2028年：申请并取得毕业证
- 毕业后：按华南师范大学当时有效的学位规定及时申请学士学位

为了申请学位，不应只以60分为复习目标。各科尽量争取70分以上，并特别关注英语、毕业论文成绩和学位申请期限。
