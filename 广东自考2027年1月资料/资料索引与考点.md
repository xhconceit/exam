## 教程与考点

### 03344 信息与网络安全管理

1. 安全基本概念：资产、威胁、脆弱性、风险；保密性、完整性、可用性。
2. 密码学、身份认证、访问控制、授权与审计。
3. 网络、主机、应用、数据与云环境安全；常见攻击与防护思路。
4. 风险评估、等级保护、安全策略、应急响应、隐私与合规。

### 08074 计算机高级程序设计

1. Python 基础：类型、表达式、输入输出、分支与循环。
2. 列表、元组、字典、集合与推导式。
3. 函数、作用域、递归、模块；字符串和正则表达式。
4. 文件读写、异常处理；类、对象、继承与多态。
5. NumPy 与数据可视化。必须自己写、运行和改错，不只背语法。

### 13009 数据库原理与技术

1. DB、DBMS、DBS；三级模式、二级映像、数据独立性；E-R 图。
2. 关系模型、完整性约束、关系代数。
3. SQL：建库建表、增删改、连接、分组聚合、子查询、视图、索引。
4. 安全、事务、锁、并发控制、备份与恢复。
5. 函数依赖、范式和分解；数据库概念/逻辑设计。

重点：每天手写并在 MySQL 中执行 SQL；尤其是连接、子查询、GROUP BY/HAVING 和 E-R 图转关系模式。

### 13011 人工智能与大数据

1. 大数据来源、特征、采集与处理框架；分布式存储和数据库。
2. MapReduce 的流程、优点和适用场景。
3. AI 概念、发展；特征提取、自然语言处理、机器学习基本思想。
4. 神经网络结构和图像识别应用；人脸识别、视频检测等案例。
5. 大数据与 AI 如何结合、数据伦理与应用风险。

## 使用顺序

1. 按指定教材建立章节笔记。
2. 13009 和 08074 每章做“可执行”练习；03344 和 13011 做术语定义、对比和案例题。
3. 最后再做历年卷/模拟卷，错题回到教材原章节。
